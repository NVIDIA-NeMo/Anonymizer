These reference predicates express bounded semantic obligations without implementing a scheduler or executor. The author read the contracts and regenerated neutral legacy corpora, not product code or product tests for attempt 418. Earlier S0 authoring exposed the author to the historical static compiler; compiler-reference-v1 remains the separate frozen compiler reference and is not replaced here. Implementation authors are different agents. No result below constitutes product acceptance or closes a historical coverage row.

Run `python calibrate.py` to execute five hand-derived tests, kill 19 source-semantic mutants and generate cases.json twice with equality checking. `python generate.py` regenerates the corpus alone. ## Alphabet, independence and bounds

Data enumerates every directed edge subset on three identities (64 graphs), codepoint windows on the literal `aé`, pairs of root windows on two independent identities with offsets 0–2, and two declared groups over selected targets 0/1 plus a foreign member 2. Existence of a total order is checked by all permutations. Root IDs remain distinct even for equal text. Coherence and atomic groups use the same partition predicate independently; neither implies a dependency or source relation. Bijective identity renaming preserves answers. Half-open touching intervals do not overlap. Empty reads are allowed. The output-window predicate assumes previously admitted nonnegative, authoritative-root ranges: it does not authorize arbitrary zero-width explicit OutputRegion declarations.

Activation enumerates all permutations of two start/terminal pairs, with and without a success-producing input prerequisite. These edges represent required input availability, not the full sequence-edge/outcome algebra: a sequence predecessor may terminate without supplying an input. Exact selected occurrence IDs are opaque strings supplied by a separate identity fixture. No equality of text or template replaces them. Complete histories require every selected occurrence to close once. Independent siblings may commute their events while preserving each start-before-terminal relation; input-dependent siblings cannot. The map predicate admits only the success category for every child; other accepted-category policies remain integration obligations. The map predicate enumerates open/closed membership, zero to two exact members, success/failed/overflow expansion and all-success/all-failure/missing terminals. Known answers also exercise mixed success/failure. Closed empty successful maps, failed maps, unknown/open maps and missing-child maps differ. The loop input is an honest complete prefix of observed controlling outcomes; the predicate cannot establish that a caller omitted no actual iteration. That attribution remains an integration obligation. The loop predicate enumerates all words of length 0–3 over continue/exit/failed at bounds 0–2, including bypass, enter-at-zero, overflow, invalid extra iteration and actual final exit index.

Requests enumerate every ordering of reserve/dispatch/Lost/settlement at physical budgets 0–2, plus exact, duplicate, missing and foreign association responses. The projection is a separate function; projections emitted for illegal histories are diagnostic mathematical results and are not valid receipt claims. Physical occupancy is dispatched requests plus live reservations at every prefix; reservation release is uncharged. `cancel_reserved` models releasing that individual reservation only: invocation-global cancellation, its stop-new-dispatch flag and cancellation propagation remain integration obligations. Semantic first terminal and independent first settlement remain immutable; late result never wins over Lost. Unknown usage is None and differs from exact zero. Resource predicates enumerate all 16 ownership/local/remote/detachment combinations. Reissue enumerates owner, replay, failure, purpose, attempt bound and next-alternate availability. Its fixed policy admits failover only for permanent/implementation_exception, as in the legacy neutral policy; it does not claim those are the only failure mappings any product policy can admit. All new eligible requests still require causal reservation and each-prefix budget checks.

Request events on distinct IDs may commute only when both prefix capacity and any association attempt bound remain valid. No claim is made that all event permutations are independent. First-terminal and first-settlement events on one ID do not commute. Resource completion and close are causally dependent. The model takes closed typed neutral inputs; nominal type admission, malformed callback payloads and enum/owner rejection precedence belong to real integration.

## Legacy disposition boundaries

mapping.json records every old family and its row count, reference predicate and remaining integration obligation. It is a family-level plan, not an old-row acceptance mapping. No legacy corpus bytes are deleted. The data corpus has 38,341 rows, activation 208 and effects 323; these are reference cases, not the 372 P7 historical acceptance IDs.

Retain real tests for authoritative multi-hop source composition, all type/ownership/precedence bounds, selected nested map/subgraph/loop identity, key/version and parent forgeries, partial membership updates, normalization/event capacity reserves, choice outcome selection, subgraph abnormal propagation, omission versus prerequisite, bound-source materialization, shared publication isolation, context consumption and initial/adaptive requests, per-association retry totals, pause/resume next to uncertain work, exact settlement defects, actual cleanup and worker occupancy. The predicates provide tiny semantic comparisons at these boundaries, not proof that production wires them correctly. Invalid or rejected declarations and deltas must still leave no retained payload or partial facts.

The accepted A1/A2 receipt/publication split is preserved: association key coverage belongs to physical response correlation; per-association publication and payload accounting are downstream integration obligations. No payload-bearing receipts are introduced by this reference. P9 forecasts and P8 continuity are outside this stage. Evidence/release predicates have a different owner. A reviewed per-row disposition plus revision-bound integration comparison remains necessary before deleting any oversized legacy machinery.
