# Compiler finite reference v1

This independent reference freezes complete observable histories for three-node chains and a selector that bypasses the middle node. Expected answers enumerate the raw product; they do not call the candidate quotient or import product code. Source author did not read the product compiler or its tests for this task; earlier S0 authoring inspected the pre-reduction compiler, so independence is implementation-author independence, not complete historical blindness.

The alphabet has node ordinals 0–2, two alternatives a/b, ports out/alternate, labels public/restricted, one context/state/evidence atom, costs 0/1, one symbolic dynamic effect, one symbolic subgraph effect, selected suffixes (1,2)/(2), and interface labels done/alternate. Eight duplication masks, 24 single-field neighbors and four selector/interface interactions yield 36 cases. The last interactions enumerate all eight raw assignments; ignored outcomes on a bypassed node do not create distinct selected histories. Alternative names alone are unobserved; selectors and interface mappings explicitly observe their meanings. Independence permits renaming unobserved alternatives; it never permits reordering dependent nodes or discarding an observable effect.

Run `python compiler_reference.py` to regenerate cases.json. Run `python -m pytest -q test_compiler_reference.py` where pytest is installed; the same four plain test functions also execute without pytest. The evidence records actual direct function execution because the system Python lacks pytest. Ten source-semantic mutants force the quotient to omit one material dimension; each must fail the conservative-equivalence assertion, rather than collection/import. Known answers independently assert 1, 2, 3 and 6 distinct histories, including the exact selected topology set.

The corpus's rejected_summary adds one cost unit to every expected history. The selftests separately alter all ten observation dimensions. Product comparison must translate declared facts, not ask production to normalize expected summaries, and compare complete history sets plus admission of correct versus rejection of perturbed summary declarations. This artifact does not itself establish that translation, a product test result or general compiler conformance.

Dynamic and subgraph entries are opaque observable atoms here: there is no independent nested-map/loop/subgraph expansion interpreter. There are no arbitrary joins, failure-category algebra, port typing, graph ownership forgeries, identity allocation rules or evidence validation semantics in this alphabet. Separate retained tests must cover those. This scope supplements rather than replaces all of workflow_static_v1 or any of the 372 historical rows.

The selected A5 work meter is implementation-specific. Integration must measure a successful complete tiny product at N visits, rerun at N and N−1, assert typed ANALYSIS_LIMIT_EXCEEDED on the latter and zero identities/callbacks/providers/resource effects in both compiler runs. Shared nested and replacement traversal must use one counter, not reset it. This reference assigns no expected numerical N and makes no timing or implementation scan-bound proof. Oversized graphs remain subject to the separately reviewed default and max_choice_states retains its existing meaning.

Manifest and evidence are frozen only after independent review; successful selftests are author evidence, not acceptance.
