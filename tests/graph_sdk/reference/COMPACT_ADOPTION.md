# Compact reference adoption history

`foundation_v2` and `evidence_v1` preserve independently reviewed finite reference bundles. The original README, manifests, corpora and review evidence remain unchanged. Their historical status and commands describe the original standalone locations. `adoption.json` records original and relocated digests; `relocation.patch` records the import-only changes needed here, including the calibration module identity. Both predicate/model source files and both corpus files are byte-identical to the reviewed originals. Source digests in a newly generated evidence manifest consequently differ from the historical manifest; all other manifest fields and corpus bytes agree.

The evidence bundle's `coverage-draft.json` campaign ledger had no test consumer and now lives in the campaign archive. Its digest stays in `frozen.json` and under `archived` in `adoption.json`. The hash-pinned evidence README still describes it as part of the original review bundle.

From the repository root, run the maintained checks:

```sh
uv run pytest tests/graph_sdk/test_compact_reference_provenance.py tests/graph_sdk/reference/foundation_v2 tests/graph_sdk/reference/evidence_v1
uv run python -c 'from tests.graph_sdk.reference.foundation_v2.calibrate import run_calibration; print(run_calibration())'
uv run python -m tests.graph_sdk.reference.evidence_v1.p7_reference.fixtures /tmp/anonymizer-evidence-regenerated
```

The foundation calibration function rewrites `cases.json` with identical regenerated bytes. Avoid the standalone calibration CLI here: its runtime evidence output would overwrite the preserved historical evidence file. No product result supplies a reference expected value.

These are 308 distinct foundation cases and 333 product tests: each of the 25 grouping cases runs separately through atomic and coherence admission. Read-window tests use non-target derived data, so empty reads remain distinct from selected output ownership. Ownership consumers use positive-width selected derived ranges; the 57 cases containing an empty ownership interval remain outside this public admission adapter. Map consumers cover real closed successful cardinalities zero through two and failed/overflow empty expansions. Loop consumers cover actual bypass, continue/exit, overflow and failure at bound two, with final-iteration artifact joins. They do not model arbitrary partial histories or forged memberships. Resources cover idle ownership/detachment only. Activation, reissue and live-resource consumers remain integration work; their predicate self-tests are not product comparisons.

The 80 evidence snapshots select consumption A, four datum/atomic topologies, subject A current/omitted and consumed XB current/stale/omitted, and all four submission selections. They compare verified target/currentness, released targets and the empty required-decision set. All submissions are actual executor-retained facts. Port, target, activation, evidence artifact and final candidate joins are also asserted directly.

This is a semantic snapshot projection, not raw graph isomorphism with the 1,680-case generator. The product fixture uses one admitted template over three targets and keeps its actual captured environment current; the reference names three templates. Each product target consumes its own bound `a` context, renamed to that target's neutral consumed label. Real binding retains versions 1 and 2 and selects version 2; the stale view uses retained version 1. The neutral snapshot uses baseline version 1 and changed version 2. Only equality/currentness is compared across this translation, never numeric version ordering. Actual versions, invocation identity and retained-source joins remain asserted in product tests.

The other 1,600 evidence cases remain unconsumed. Exclusions include A consuming B/AB/decision, decision ancestry, target-specific configuration/absence/state changes and stale subject A. The predicate's intermediate `eligible` set and complete neutral verified row are not asserted by this consumer. Decisions, dynamic membership, malformed ownership and error precedence retain their separate integration obligations.

At this initial adoption checkpoint no legacy interpreter, corpus, fixture or test had been deleted. Later independent retirement review authorized replacing the broad interpreters with authenticated frozen answers, compact models and actual owner-boundary witnesses. The current archive loader and maintained checks are described in [the reference README](README.md). The initial counts above remain historical: they do not grant historical P7 acceptance, legacy equivalence or full PR1 completion.
